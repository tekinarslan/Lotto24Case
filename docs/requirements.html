Introduction

In Germany there are two major draw-based lotteries:

  • Lotto 6aus49: In this lottery, players select six numbers from a pool of 49 and an additional "Super Number" between 0 and 9. There is a draw where drawn numbers are compared to picked numbers. The prize depends on how many numbers match the drawn winning numbers.
  • Eurojackpot: Players choose five numbers from a pool of 50 and two "Euro Numbers" from a separate pool of 12. To win the jackpot, all seven numbers must be correct.
  • Supplementary lotteries: These are optional lottery games, such as Spiel 77 or Super 6, which can be played alongside the main lottery and offer additional chances to win.

Each lottery draw has

  • A last draw date with draw results (which numbers were drawn on this draw date)
  • Next draw date in the future (in which players can participate)
  • Maybe a jackpot height (directly after a draw it is not there, because it is not known if a player has picked the right numbers, yet)

User Story

As a user I want

  • To install an app on my Android device which is small and just displays the results of my favorite lotteries
  • The last draw results for LOTTO 6aus49 and Eurojackpot
  • The jackpot heights (if there are any)
  • and the next draw date(s) to be visible in a "draw results" screen or (bonus) a draw result widget

so, I can decide if I want to participate in the next draw.

Features to be implemented.

Must have:

  • Actual numbers are displayed in a ball
  • Next draw date is displayed
  • The jackpot heights are displayed (if applicable)
  • Jetpack Compose should be used as a framework

Bonus:

  • There is also a widget
  • If you click anywhere, it will open a link to our website or to our native app’s Play Store page
  • Spiel77 and SUPER6 are also displayed.
