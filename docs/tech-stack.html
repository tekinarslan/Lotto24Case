3. Core Architectural Principles

  • Unidirectional Data Flow (UDF): Single StateFlow<DrawResultsUiState> emitted by DrawResultsViewModel.
  • Dependency Inversion: Domain defines repository and navigator interfaces; Data and Platform layers implement them.
  • Session In-Memory Cache & Failure Resilience: Uses a session-scoped in-memory cache retaining previous draw results; if a refresh fails due to network outage, existing numbers are retained with an informational status banner rather than wiping the screen.
  • Physics-based Motion: Compose spring() physics for natural ball bounce and card press micro-interactions.
